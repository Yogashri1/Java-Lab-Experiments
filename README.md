# U25CSG13 - Object Oriented Programming Using Java Laboratory

A collection of Java programming laboratory experiments completed as part of the **Computer Science and Engineering (CSE)** curriculum.

## 📌 About This Repository

This repository contains the programs and laboratory experiments completed for the course **U25CSG13 - Object Oriented Programming Using Java Laboratory**.

The experiments are organized systematically to demonstrate the practical implementation of Java programming concepts and **Object-Oriented Programming (OOP)** principles.

## 🎯 Objectives

The main objectives of this repository are to:

* Develop programming skills using Java.
* Understand and implement Object-Oriented Programming concepts.
* Apply Java concepts to solve programming problems.
* Strengthen logical thinking and problem-solving skills through practical experiments.
* Maintain and document laboratory work using Git and GitHub.

## 🛠️ Technologies Used

* **Programming Language:** Java
* **Development Kit:** Java Development Kit (JDK)
* **Version Control:** Git
* **Repository Hosting:** GitHub

## ▶️ How to Run

1. Install the Java Development Kit (JDK).
2. Clone this repository to your local system.
3. Navigate to the required experiment folder.
4. Compile the Java source file using:

```bash
javac Program.java
```

5. Run the compiled program using:

```bash
java Program
```

> The file name and class name may vary for each experiment.
